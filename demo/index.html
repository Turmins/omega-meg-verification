V1: просмотр сохранённых решений

Эта страница объясняет подготовку настоящего локального демо. Само демо содержит сохранённые TEST-решения фазового метода и Siamese CNN. Модель в браузере не запускается; EEGNet/Graph относятся к отдельному V2 эксперименту.

Из корня репозитория выполните в PowerShell:

py -3.10 -B tools\prepare_saved_demo.py --archive-root ..\deep_learning_extension
Invoke-Item .\local_artifacts\verification_v1\report\demo.html

После подготовки HTML не требует Python, GPU или сети. Повторный импорт в занятую папку остановится; просто откройте уже созданный HTML. Нужен разрешённый локальный архив, полные индивидуальные scores в Git не включены.
