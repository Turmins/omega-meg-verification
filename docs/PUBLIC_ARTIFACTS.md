# Публичные артефакты учебного проекта

Обученные веса — собственные результаты проекта. По прямому указанию пользователя
и после подтверждения авторства включены 18 tensor-only checkpoint-файлов
в `weights/`. Они совпадают с исходными байт-в-байт и загружаются строго в
неизменённые архитектуры. Сторонние pretrained checkpoints в проверенных путях
обучения не использовались.

Веса, исходные данные и индивидуальные результаты — разные артефакты.
[Страница OMEGA](https://www.mcgill.ca/bic/neuroinformatics/omega) ограничивает
перераспространение полученных данных, но не содержит отдельного положения
о trained weights. Прежний pending-флаг был дополнительной осторожностью этой
подготовки, а не установленным запретом на собственные веса. Точная версия
исходного соглашения для локального экспорта не документирована; права на передачу
исходных записей из этого вывода не следуют. Лицензия собственных кода/весов
выбирается владельцем отдельно до внешнего релиза.

Исходные MEG, списки участников, participant embeddings, персональные шаблоны
и индивидуальные scores не включены. Полный исторический replay остаётся
приватным. Веса содержат параметры и обычные BatchNorm buffers. Наличие
memorization не установлено; отсутствие текстовых ID не доказывает отсутствие
любой информации, усвоенной моделью.

`demo/index.html` автономно показывает реальные агрегированные таблицы и отдельно
синтетические примеры score/порога. Это не inference и не индивидуальный TEST replay.
Google Drive URL в README оставлен незаполненным. Данные, ссылка и её права доступа
не публиковались и не изменялись.

18 файлов суммарно 3,30 МБ, максимальный файл 419,559 bytes; обычный Git подходит,
LFS по размеру не требуется ([GitHub limits](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github)).
Исторический архив и научные manifests сохранены без изменений; GitHub push не выполнен.
